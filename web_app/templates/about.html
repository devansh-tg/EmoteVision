Methodology and system design

A concise view of the model, pipeline, evaluation points, and deployment architecture used in EmoteVision.

Problem Statement

EmoteVision detects facial expressions from a live camera feed and classifies them into seven emotion classes: Angry, Disgust, Fear, Happy, Neutral, Sad, and Surprise.

Technical Stack

  • Python, Flask, and Flask-SocketIO for real-time backend delivery
  • TensorFlow/Keras CNN for emotion classification
  • OpenCV Haar Cascade with optional MediaPipe face detection
  • Chart.js and vanilla JavaScript for live analytics

Model Pipeline

  1. Read the latest frame from a shared camera buffer.
  2. Detect face bounding boxes in the frame.
  3. Crop, resize, normalize, and enhance the face region.
  4. Run 7-class softmax inference with the trained CNN.
  5. Smooth primary-face probabilities to reduce flicker.
  6. Publish results to the browser through Socket.IO.

Model Details

Input
48 x 48 grayscale face crop
Architecture
4 convolutional blocks with BatchNorm and dropout
Output
7-class softmax probability vector
Dataset
FER-2013 formatted train/test image folders
